# Egeria - Apache Atlas Connector
  
**As of June 2022, this repository is not being maintained.**

This repository provided a connector for Apache Atlas

More details can be found in the [original README](README-main.md)

If you are interested in working on the connector, or you have a need to make use of the connectors, please do [get in touch with the community](https://egeria-project.org/guides/community/) via slack, mailing lists, or our calls & we will work together to see if we can help you.

We are in the process of re-invigorating this connector. 
See https://github.com/odpi/egeria-connector-hadoop-ecosystem/issues/464 for further information.
