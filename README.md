# Egeria - Apache Atlas Connector
  
**As of June 2022, this repository is not being maintained.**

This repository provided a connector for Apache Atlas

More details can be found in the [original README](README-main.md)

At this time the core team is not working on this repository due to other priorities. However if you are interested in working on the connectors, or you have a need to make use of the connectors, please do [get in touch with the community](https://egeria-project.org/guides/community/) via slack, mailing lists, or our calls & we will work together to see if we can help you.

Some of the work needed to reinvigorate this connector includes
 * Moving to Java 11 (required by Egeria) but also working with Java 8 to connector to Atlas
 * using latest version of Apache Atlas
 * Having a core maintainer/owner who's invested in the connector
 * Testing & Fixing bugs
 * Working on building automated testing

The repository will shortly be archived for clarity, though this will be reversed if work resumes.
